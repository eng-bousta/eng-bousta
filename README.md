## ⛑️ 04 — Smart Industrial Safety Helmet

**Academic Project — Industrial IoT & Embedded Safety**

Connected PPE designed to improve worker safety in hazardous industrial environments through real-time monitoring, event detection and wireless alert transmission.

- 🔄 Fall detection using MPU6050 accelerometer + gyroscope
- ☠️ Hazardous gas monitoring with MQ-135 for NH₃-related detection
- 📍 GPS geolocation using NEO-6M
- 🆘 Manual SOS / emergency cancellation button
- 🔊 Local alerts: buzzer, LED and vibration motor
- 📡 Long-range communication using LoRa RF96
- 📱 Cellular communication using SIM800L
- 🔋 Power management: Deep Sleep / Light Sleep
- ⚡ Target local alert response: < 500 ms
- 🔋 Target monitoring autonomy: ~48 h

**Stack:** `ESP32` `FreeRTOS` `MPU6050` `MQ-135` `GPS NEO-6M` `LoRa RF96` `SIM800L` `PlatformIO` `C/C++`
